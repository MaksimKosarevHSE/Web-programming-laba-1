# «После титров»

Мы сделали учебный сайт небольшого киноклуба.

## Что есть в проекте

- три HTML-страницы: главная, каталог и страница о клубе;
- mobile-first адаптивная вёрстка;
- сетки на Flexbox и Grid;
- фильтр каталога по жанрам;
- форма с ответом на странице;

## Файловая структура

```text
posle-titrov/
├── index.html
├── catalog.html
├── about.html
├── styles.css
├── app.js
└── assets/
```

Все фильмы и описания вымышлены.
